# Анализ заполняемости книжного шкафа

## 🎯 Цель
Разработка системы на основе нейронной сети YOLOv8 для анализа заполненности книжного шкафа по загруженному изображению.

## 📦 Структура проекта
- `app.py` — основной Flask-сервер
- `requirements.txt` — зависимости
- `templates/index.html` — веб-интерфейс
- `static/result.jpg` — результаты обработки
- `history.db` — история запросов
- `reports/report_generator.py` — генерация PDF и Excel отчётов
